# 企业分布热力图 Skill

一句话查询产业企业，生成可缩放的交互地图和1920×1080汇报图片。

> 初版 v0.1.1。支持标准 SKILL.md，模型不限GPT；需要自己的Techin MCP授权、本地Python、联网浏览器；非商业学习研究可自动获取行政边界。公开包不附带企业数据库、开发者Key或测试边界。

## 能做什么

- 按Techin产业分类，完整翻页取得存续企业，核对数量与信用代码唯一性。
- 交互网页：热力／集聚气泡、行政区蓝线、范围外淡化、企业地址弹窗。
- 16:9 PNG：浅蓝标题、企业总数、国高、专精特新、小巨人、上市数量，以及短标签代表企业。
- 原始数据和审计文件留在使用者本地。异常过多会暂停正式出图。

## 三步使用

1. 把仓库里的 `enterprise-heatmap` 文件夹安装到Agent的技能目录，见[安装说明](docs/INSTALL.md)。不要复制整个仓库作为一个Skill。
2. 在自己的Agent连接设置中配置Techin官方服务地址和自己的 `X-Techin-Api-Key`。不要在聊天中发送Key，见[Techin配置](docs/TECHIN.md)。
3. 对Agent说：

> 使用enterprise-heatmap，生成深圳市宝安区高性能材料产业企业分布：交互网页＋16:9高清图片。仅用于非商业学习研究，请自动获取对应行政边界。输出保存到我指定的本地目录。

需要Python 3.9或更新版本，无须pip安装依赖。生成后用浏览器打开HTML；图片导出页点击“导出PNG”。需要联网加载底图与前端资源，第一次安装在中国大陆需实测网络可达性。底图免地图Key；Techin账号和模型费用取决于各自服务。

## 边界使用条件

默认边界来源仅供非商业学习研究，商业用途需另行授权
