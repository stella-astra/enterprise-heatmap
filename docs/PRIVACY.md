# 公开包隐私范围

公开包从明确文件清单构建，不是把工作区直接压缩。

包含：通用Skill指令、Python脚本、无数据HTML模板、中文说明、发布和验证工具。

不包含：开发者Techin Key、模型Key、MCP配置、个人目录、用户名、邮箱、测试企业JSON、信用代码清单、截图、已生成地图、查询日志、原WorkBuddy交付包、候选边界或Git历史。

check_release.py检测常见Key模式、个人绝对路径、邮箱、信用代码样式、未知文件与符号链接；检查结果只能代表发布包范围，不证明聊天历史或本机其他文件已清除。开发机器连接保留供本人使用，不会随Skill转移。实际查询结果属于用户本地输出，不得作为公共仓库内容。

发布ZIP及SHA256校验值可用于确认上传文件未被修改。这个项目不提供集中共享Techin账号，每个人必须使用自己的授权。
